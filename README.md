# UTS_PCD_202331070_C_ITPLN

Repository ini berisi proyek Ujian Tengah Semester (UTS) untuk Mata Kuliah **Pengolahan Citra Digital** Tahun 2025 di ITPLN.

## 📷 Deskripsi Proyek

Proyek ini terdiri dari beberapa tahapan pengolahan citra menggunakan bahasa pemrograman **Python** dengan bantuan library **OpenCV** dan **Matplotlib**. Seluruh gambar yang digunakan diambil secara pribadi sesuai instruksi dosen.

### 🔍 1. Deteksi Warna
- Deteksi warna **Merah**, **Hijau**, dan **Biru** pada citra yang berisi tulisan nama lengkap.
- Pengolahan dilakukan menggunakan model warna **HSV**.
- Disertai histogram dan analisis warna.

### 📊 2. Penentuan Ambang Batas (Threshold)
- Menentukan nilai ambang batas HSV terkecil hingga terbesar untuk mendeteksi masing-masing warna.
- Ambang batas disesuaikan secara eksperimen dan dijelaskan pada laporan.

### 🌞 3. Perbaikan Gambar Backlight
- Gambar backlight diambil secara pribadi dengan sumber cahaya di belakang objek.
- Diperbaiki menggunakan teknik:
  - Grayscale conversion
  - Brightness adjustment
  - Contrast enhancement
  - Kombinasi brightness & contrast
- Fokus perbaikan pada peningkatan visibilitas profil wajah/tubuh.

### 📄 4. Laporan
- Laporan disusun dalam format PDF sesuai template dosen.
- Berisi dokumentasi gambar, penjelasan kode, hasil, dan analisis.
